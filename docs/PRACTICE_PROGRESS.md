# 练习进度保存与恢复

记录日期：2026-10-20。适用范围：当前浏览器中的全文与分句练习；不增加账号数据库或跨设备同步。

## 目标与交互

练习到一半关闭网页，刷新或再次打开网站时，恢复上次选用的范文、练习模式、已输入内容和练习位置，无需手动保存。每篇范文分别保存进度，全文与分句两种模式互不覆盖。恢复成功时以简短提示告知“已恢复上次练习”，不自动发起 AI 请求，不自动开始秒表。

“练习位置”包含输入框内的光标或选择范围、对应的单词位置，以及页面滚动位置。恢复时以保存的正文和输入为依据重新生成页面，不保存整页 HTML；修改过错误文字后仍可继续输入和核对。

| 范围 | 保存和恢复的内容 |
| --- | --- |
| 通用 | 当前范文、当前练习模式 |
| 全文模式 | 已输入的全部文字、输入光标或选择范围、对应的单词位置、页面滚动位置；核对标记按正文与输入重新计算 |
| 分句模式 | 每组句数、各组已输入文字、当前组及组内光标或选择范围、对应的单词位置、页面滚动位置、英文范文的显示或隐藏选择、本地“逐词核对”状态、各组折叠选择及 AI 已通过的完成标志 |

输入过程自动保存；移动光标、切换模式或文章、切换分句显示或折叠状态及滚动位置时，也更新相应进度。连续变化在最后一次操作 350 毫秒后合并保存，避免每个按键都写浏览器存储；页面隐藏或离开时，通过 `visibilitychange` / `pagehide` 立即保存已经完成的输入。输入法组合文字期间不保存中间状态，完成组合后再保存。恢复位置不会主动聚焦输入框或弹出手机软键盘；点击输入区即可继续练习。

## 文章与进度的生命周期

- 导入新文章：建立新的进度；其他历史文章的进度保留。
- 重复导入：正文去除首尾空白后与已有范文相同，复用该篇文章并恢复原进度；内部空格和换行仍参与文章去重。
- 从“最近范文”载入：恢复该篇文章自己的两种模式进度；载入不改变原有按导入顺序清理的规则。
- 切换全文／分句：保留离开模式的进度，恢复目标模式的输入与位置。
- 点击“重新练习”：只清除当前文章、当前模式的进度及该模式秒表，另一模式保留。
- 修改每组句数后点击“应用分组”：按新的每组句数重新建立分句练习，清除原分组草稿与位置，全文进度保留；句数没有变化时不清空草稿。
- 改名：只修改标题，不清除进度。
- 手动删除文章，或导入第 11 篇时自动清理最早文章：一起删除对应进度。删除当前文章不打断页面中本次练习，但不再为已删除的历史记录继续保存进度。
- 全部历史文章删除：下次打开使用示例范文，不恢复已删除文章的练习现场。

最近范文仍最多保留 10 篇。示例文章的进度与自定义文章分开处理，不占最近范文名额。

## 存储结构与兼容

沿用已有的 localStorage 键 `mars-ielts-typing:article:v1`，文章列表、当前文章及其进度在一次写入中一起保存，不另建数据库。外层数据版本保持 `version: 1`；每篇文章可选带 `progress`，示例文章另存在顶层的 `sampleProgress`。旧数据没有这些字段时仍可载入原范文，从空白进度开始。

进度自身也使用 `version: 1`，只接受明确列出的字段：

| 字段 | 内容 |
| --- | --- |
| `mode` | 上次使用的 `realtime` 或 `sentence` 模式 |
| `realtime` | `value` 输入文本、`selectionStart` / `selectionEnd` / `selectionDirection` 选择范围、`scrollY` 页面位置 |
| `sentence` | `groupSize` 每组句数、`activeGroup` 当前组、`scrollY` 页面位置、`groups` 各组状态 |
| `sentence.groups[]` | `draft` 草稿、选择范围及方向、`referenceVisible` 英文范文显示状态、`scrollTop` 输入区滚动位置、`checked` 本地核对状态、`collapsed` 折叠状态、`reviewCompleted` AI 已通过的完成标志 |
| `scrollY` | 当前模式的页面位置 |

单词位置根据保存的输入文本和光标偏移恢复，不额外保存一个可能随编辑失效的单词序号。模式切换分别使用各模式保存的页面位置。

每份进度中，全文和所有分句草稿合计最多 1,000,000 个 UTF-16 码元，分句最多 10,000 组。这是应用校验上限，不代表浏览器保证提供足够存储空间。超出上限或结构无效时拒绝保存整份新快照，不截断草稿；已有有效记录保留，当前页面仍可继续练习。读取时限制光标、当前组和滚动偏移在有效范围内，未知字段不进入恢复状态。

## 数据边界与失败处理

进度使用当前网站地址下的浏览器本地存储，与账号登录状态分开。退出登录不会主动删除范文和进度；同一浏览器配置中的其他使用者也可能看到这些本地内容。不同浏览器、不同网站地址（例如本地预览与正式网站）、不同设备之间不共享进度。清除网站数据后，本地范文和进度都会消失。

本地“逐词核对”保存是否处于核对状态，恢复时按范文和草稿重新计算，不保存结果 HTML。AI 表达评析之后恢复为可编辑草稿，不以严格逐词核对替代 AI 评析，以免把有效改写误标为错误。语言正确且原意一致的 AI 评析只额外保存 `reviewCompleted` 布尔完成标志，用于恢复组状态和绿色进度格；不持久化 AI 翻译、学习或表达评析的结果内容，也不保存正在进行的请求。点击“修改输入”返回编辑即开始新一轮修改，清除该组完成标志；AI 已通过草稿刷新后保持可编辑，首次实际输入时清除恢复的完成标志。两者均需重新检查后再算完成，折叠、展开和进度导航不会清除完成状态。刷新后需要用户主动点击才重新请求 AI。秒表仍是手动计时：恢复练习不自动开始，刷新仍按原规则重置计时。

各组 `collapsed` 独立保存；缺少该字段的旧进度按展开处理。折叠不清空草稿、检查结果或范文显示选择，也不改变完成状态和秒表。点击总体进度格时先展开对应组，再跳到组标题，不自动聚焦输入框。重练和真正改变每组句数后的重新分组清除折叠及完成状态。完整交互规则见 [分组折叠与总体进度](SENTENCE_GROUPS.md)。

浏览器存储被禁止、空间不足或记录损坏时，不应清空当前输入或阻止本次练习。进度恢复和保存失败使用独立的 `practiceProgressNotice` 提示区域，不与文章历史保存提示混用。新进度只有完整写入成功后才替换持久记录；失败时保留当前草稿和原有有效记录，不写入不完整进度。无法恢复的记录跳过，不执行其中的内容。输入和文章按纯文本读取并在当前页面重新校验。

切换范文或导入另一篇之前，先立即保存当前尚未落盘的草稿；若本次保存失败，中止文章切换或替换，并在当前面板内提示原因，当前文章和输入继续保留。排除存储问题后可再次操作，不把未保存草稿悄悄丢弃。读取到已经被另一页面删除的历史文章时，也不通过延迟保存重新建立记录。

- [x] 关闭页面再打开：恢复上次练习，不自动开始秒表，不自动请求 AI。
- [x] 分句设置每组句数，在多个组输入并隐藏部分范文，刷新后恢复分组、草稿、显示选择和当前组位置。
- [x] 同一篇文章切换模式，两种进度分别保留；切换文章、重复导入时恢复对应文章进度。
- [x] 重练只清除当前模式；重新分组只重置分句进度；标题修改不影响进度。
- [x] 删除历史文章、删除当前文章和超过 10 篇自动清理时，对应进度不会重新出现。
- [x] 存储不可用、写入失败或记录损坏时，练习不中断，提示明确，未受影响的记录可恢复。
- [x] 手机和桌面恢复位置合理，不强制弹出软键盘，原有选区学习、权限限制和计时功能不受影响。
