# 分组折叠与总体进度

记录日期：2026-10-20。适用范围：分句模式的分组收纳、完成状态与总体导航；与本次行内漏词标记简化一起验收和发布。

## 每组折叠

每一组都可手动展开或折叠，不限于已完成的组。新建分组默认展开，核对或评析结束后不自动折叠，用户可先查看结果再决定收起。折叠入口位于各组标题处，支持鼠标、触屏与键盘操作，并以展开状态告知辅助技术。

折叠后仅保留组号、句数和当前练习状态，不展示范文摘要。英文范文、中文翻译、输入区、检查结果和操作按钮一起收起，避免默写时在标题中提前看到答案。重新展开保留原草稿、检查状态和范文显示选择；折叠本身不清空内容、不调用 AI、不改变秒表。

分组区域提供“全部展开 / 全部折叠”。原来的范文批量操作明确命名为“显示全部范文 / 隐藏全部范文”，只控制英文范文的可见性，不改变整组的展开或折叠选择。各组标题和状态在折叠后仍可查看。

## 总体进度与跳转

总体进度位于分组设置下方、第一组内容上方，与完成数量合并显示。按文章顺序为每组显示一个进度格，例如 7 组对应 7 格：完成为绿色，未完成为灰色。文字同时显示已完成数量及总组数，状态不只依赖颜色表达。

点击任意进度格，会展开对应组并跳到组标题；不会主动聚焦输入框或弹出手机软键盘。该操作只导航，不核对、不发起 AI 请求、不启动秒表。手机窄屏或组数较多时进度格自动换行，不把页面横向撑开。

完成状态按检查结果判断：

| 情况 | 是否计为完成 |
| --- | --- |
| 未输入，或只输入了草稿尚未检查 | 否 |
| 逐词核对全部正确 | 是 |
| 逐词核对有错词、多词或漏词 | 否 |
| AI 表达评析确认语言正确且原意一致 | 是，允许与范文不同的正确改写 |
| AI 表达评析有语言错误或原意不一致 | 否 |
| AI 请求中、失败或取消 | 不作为通过检查的依据 |
| 只折叠、展开或切换范文显示 | 不改变已有完成状态 |
| 点击“修改输入”返回编辑 | 清除该组完成标志，开始新一轮修改，须重新检查 |

展开已完成组不会取消完成，进度格导航也不会取消完成。点击“修改输入”返回编辑时，视为开始新一轮修改，即使尚未改变文字，也清除该组完成标志并等待重新检查，沿用已有的结果返回编辑行为。AI 已通过的草稿刷新后恢复为可编辑内容，首次实际输入时清除恢复的完成标志。重新练习重置当前模式，重新分组建立新的分句状态；每组句数未改变时沿用既有草稿与状态，不作无意义重置。

## 保存、恢复与兼容

沿用 [练习进度保存与恢复](PRACTICE_PROGRESS.md) 的浏览器本地存储规则。每组新增 `collapsed` 布尔折叠状态和 `reviewCompleted` 布尔 AI 完成标志，仍在 `mars-ielts-typing:article:v1` 的文章进度中保存。示例范文使用独立的示例进度，文章之间互不覆盖。

旧进度没有新增字段时，默认所有组展开、无 AI 完成标志。本地逐词核对的完成状态继续依据范文和草稿重新计算；AI 已通过的状态只保存一个完成标志，不保存评析正文、错误说明或结果 HTML。恢复后保留绿色完成格，草稿仍可编辑，不会自动补发 AI 请求。恢复的 AI 草稿首次实际输入后清除旧完成标志；结果状态下点击“修改输入”返回编辑时立即清除完成标志。

重新练习或真正重新分组时，折叠选择和对应完成状态一起重置。切换模式或文章不会抹掉该篇分句记录。手动删除文章、最近 10 篇先进先出清理、清除网站数据等行为与既有进度一致；不增加账号数据库或跨设备同步。
