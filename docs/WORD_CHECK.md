# 逐词核对与漏词定位

记录日期：2026-10-20。适用范围：分句模式的本地“逐词核对”，不改变 AI“表达评析”的判断规则。

## 结果显示与修改

核对以当前组的范文和草稿为依据，比较用词、大小写和标点，忽略空格数量和换行差异。结果保留用户的原输入文字：错词继续用红色提示；漏词在检查结果的对应位置插入琥珀色虚线按钮，例如 `as`，只显示所漏单词，不再附加“漏”字。琥珀色、虚线边框及底部漏词提示共同区分漏写与写错，无需对照底部列表猜测位置。

底部仍显示错误统计和漏词列表。点击结果中的漏词标记，或底部对应的漏词按钮，返回该组原输入，将光标移到建议补写的位置。按钮支持键盘聚焦与激活。定位只帮助用户修改，不自动补词、不替换原草稿，也不发起 AI 请求。

空白答案沿用“请先输入”的提示，不在空结果中铺出整组范文。用户修改后可重新核对，标记随新草稿重新计算。

## 位置与恢复规则

- 连续漏写的词按范文顺序标记，定位到同一个补写边界；每个按钮显示其对应的漏词。
- 漏词后还有实际输入的词时，定位到下一个词的起始位置；句首漏词也按此规则，保留原输入的前导空白。句尾漏词定位到最后一个实际词结束的位置，在原有尾部空白之前；没有实际输入词时使用偏移 `0`。
- 空格、制表符、换行仍保留在原草稿中，定位使用原草稿的字符偏移，不按压缩空白后的结果移动光标。
- 输入光标采用浏览器原生的 UTF-16 偏移；输入中存在代理对字符时，后续位置仍以原文字为准。
- 本地进度只保存草稿和是否处于逐词核对状态。刷新恢复时重新计算漏词位置及结果按钮，不保存或执行结果 HTML，也不请求 AI。进度规则见 [练习进度保存与恢复](PRACTICE_PROGRESS.md)。

逐词对齐存在多个同样合理的位置时，沿用本地核对算法确定的顺序；定位是与范文精确对照的修改提示，不是对同义改写或语义正确性的判断。表达不同但意思相同的情况仍可使用“表达评析”。
