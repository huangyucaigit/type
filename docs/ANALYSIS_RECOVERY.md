# 翻译与学习：结构化结果兜底

更新日期：2026-10-21。适用独立的“翻译与学习 / 整句”弹层及 `/api/analyze`；不转入助手，不修改助手接口。

## 处理顺序

1. 继续使用 JSON 输出模式和原学习提示词，校验原有字段、类型、数量和长度。
2. 校验失败时本地提取完整 JSON 对象，再做同样的校验。支持 Markdown 代码块和前后解释文字；扫描器识别字符串、转义符及嵌套花括号，不用正则匹配整个 JSON。最多检查 60,000 字符、8 个候选对象，不执行模型内容。
3. 仍不合格，自动重新生成一次，补充格式要求。保持相同选区和上下文，不把错误正文拼入系统提示词。两次请求合计最多 30 秒、始终占一个共享并发名额；弹层在此期间保持加载。同一选区和上下文的并发请求仍合并。
4. 两次均无合格结构，但有完整、可读的模型回答，返回 `fallbackText`。对于可解析但结构不合格的对象，只提取 `translation` 及可读的 `brief/details` 内容；不展示未知字段。对于普通解释正文，保留为纯文本。最多 16,000 字符，不裁断句子硬凑结果。
5. 没有可用正文时，显示友好的失败提示和“重试分析”。空响应、破损 JSON、超长内容、被截断的生成结果不直接展示。网络、鉴权、额度、限流和 HTTP 服务错误不自动重复请求；若第二次请求发生此类错误，仍可保留第一次完整的可读回答。

## 页面与缓存

- 正常及本地恢复成功的结果，仍显示原翻译、简要学习、展开学习，继续缓存。
- 纯文本结果仍在同一个独立弹层，用 `textContent` 渲染，保留换行，不解析 HTML。
- 显示“当前以简洁文本展示，可重试获取完整学习卡片。”及“重试分析”，不显示空的展开学习区域。
- 纯文本降级和失败在前后端均不缓存。手动重试会重新请求，成功后恢复完整卡片和缓存。
- 切换选区、关闭弹层、更换范文后，旧请求不能覆盖当前界面。
- 后端只从成功的模型消息 `choices[0].message.content` 提取学习内容，绝不将上游 HTTP 错误正文或诊断异常交给前端降级显示。
