# 学习助手快捷提问

日期：2026-10-21。状态：本地实现，待用户查看，不部署。

## 目标与范围

用户把范文选区“添加到助手”后，可直接点击快捷提问，无需自己组织提示词。仅影响右侧/手机学习助手及 `/api/assistant`；原独立“翻译与学习 / 整句”弹层、提示词、缓存和 `/api/analyze` 继续独立。

首版固定六个模板，不增加管理后台或额外的 AI 分类调用。通用约束是结合引用语境、只分析本轮目标、简洁中文、默认 1–3 个重点和最多一个英文例句；不截断模型输出。仿写练习例外：作答前不提供答案或示例。

| 模板 | 学习目标 |
| --- | --- |
| 句子拆解 | 先概括意思，再拆主干和一个关键结构；段落只挑一个值得学的句子 |
| 词汇搭配 | 1–3 个实用表达的语境含义和用法；短选区只围绕该表达 |
| 仿写练习 | 一次一道题，保留关键结构；单词/短语用造句题；用户作答后才点评 |
| 同义替换 | 两个语境适用的替换，说明差异和替换限制 |
| 自然改写 | 一个保留原意的自然版本及关键改动；原文好时不强行修改 |
| 写作应用 | 一个可迁移的表达或句式及一个新话题例句；重视自然准确，不打分 |

## 推荐与布局

助手输入框上方显示目标引用摘要和 2–3 个推荐按钮，“更多”展开剩余项，六项均可访问。手机按钮增大点击区域，允许换行；菜单不覆盖输入框。

| 引用内容 | 推荐 |
| --- | --- |
| 单词/短语 | 词汇搭配、同义替换 |
| 单句/较短片段 | 句子拆解、仿写练习、自然改写 |
| 多句/段落 | 词汇搭配、写作应用、仿写练习 |

分类只用于推荐排序，基于选区词数、句末标点和段落换行，不声称精准句法判断。单词包括词尾标点；短语通常不超过六词且无句末标点；单句不超过八十词；其余归为长文本。必要时用户可在“更多”选择其他学习目标。仍遵守现有单次选区 2,000 字符限制，不增加整篇长文选区通道。

没有任何可用引用时，显示“选中范文并添加到助手，即可快捷学习。”普通聊天仍可使用。

## 发送、学习对象与保存

- 新添加的引用默认成为目标；多个待发送引用时显示“针对引用 N”和英文摘要。重复添加已有引用会将其设为目标，不重复保存。
- 快捷项点击直接发送相应问题，只携带目标这一条引用；其他待发送引用保留。普通输入发送仍携带全部待发送引用。
- 快捷发送不清空或覆盖输入草稿。权限校验失败时引用和草稿也保留。
- 对话气泡显示简短、易读的提问，模型接收完整的学习目标与回答约束；历史与重试仍保留完整提示词。
- 发送后保持学习对象，显示“继续学习上次引用”，方便连续点击其他模板。不会因为还留着较早待发送引用就跳回旧对象。
- 推荐项、更多项在准备请求和生成期间禁用；同步发送锁防止重复点击。仍可用原停止、错误重试、重新生成和普通追问。
- 清空对话同时清空当前学习对象。删除未发送引用后回落到其他有效引用；不存在引用时不发请求。
- 目标 ID 随浏览器对话记录保存，恢复时仅接受仍存在于待发送引用或历史用户消息中的 ID；旧记录无此字段仍可读取。按身份、范文隔离及删除清理沿用原规则。

## 实现位置

- `assistant/src/quick-questions.mjs`：六个模板、轻量推荐、目标解析。
- `assistant/src/components/Assistant/QuickQuestions.tsx`：目标摘要、推荐按钮及“更多”。
- `assistant/src/hooks/useAssistant.ts`：快捷发送、保留草稿和其他引用、生成互斥。
- `assistant-history.js`：目标 ID 校验和持久化。
- `learning-assistant.js` / `.css`：由助手子项目构建，刷新主站即可使用。

## 验收清单

| 要求 | 验证方式 |
| --- | --- |
| 六个目标各有对应提示词 | 自动测试及浏览器逐项发送，检查模型侧请求 |
| 单词、短语、单句、段落推荐不同 | 规则测试、实际范文选区和面板检查 |
| 添加引用/展开更多不调用 AI | 浏览器网络记录 |
| 多引用只发送最新目标，其余保留 | 两段引用端到端检查请求及待发送列表 |
| 草稿不丢失、可继续学习、刷新保留目标 | 输入草稿后快捷发送、连续提问、刷新 |
| 生成中防连点、失败后重试、普通追问及仿写作答 | 浏览器受控模型检查状态和上下文 |
| 没有引用、移除引用、清空对话 | 空态、删除、确认清空检查 |
| 翻译与学习仍独立 | 原选区测试；助手打开时点击原“翻译与学习”，检查 `/api/analyze` 及草稿/引用 |
| 桌面与手机控件可达、不溢出 | 1440×960、390×844、320×700 截图及边界检查 |

浏览器异常探索包括生成期间切换引用、首次失败后重试、清空后的空态及刷新后仍保留未发送草稿。受控模型验证交互，真实模型抽查回答目标；不以模拟回复证明教学质量。
