## 手动秒表

两种练习模式各有独立秒表。点击“开始”计时，“暂停”后点击“继续”累计计时；“清空”只归零并等待重新开始，保留范文、输入和检查结果。输入、检查及完成练习都不会自动启动或暂停秒表。隐藏秒表或切换窗口不会改变计时状态；切换练习模式保留各自时间。“重新练习”重置当前模式的输入与秒表，导入新范文重置两种模式，重新分组重置分句模式。

## 公开留言反馈

首页和帮助页的“留言反馈”进入 `feedback.html`。留言提交后立即公开，昵称可不填，正文需 5–1000 个 Unicode 字符；页面以纯文本显示内容，提供最新留言和分页，不生成示例留言。留言板不进入搜索索引。直接双击本地文件时不能提交或读取公共留言，需通过本地服务或正式网站打开。

浏览器指纹（Browser Fingerprint，把浏览器特征组合成识别摘要）仅在访客勾选同意后计算。摘要依据浏览器版本、语言、平台、时区、屏幕可用尺寸与色深、处理器并行数，使用浏览器内置 SHA-256 摘要算法；原始特征不发送给服务器，无第三方指纹脚本。摘要功能需要 HTTPS 或 localhost/127.0.0.1 的安全环境。页面未同意时仍可浏览公开留言。

匿名 Cookie（浏览器保存并自动带回服务器的小型标识）由服务端签名，使用 HttpOnly、SameSite=Strict，在正式 HTTPS 域名附加 Secure。跨站请求伪造防护令牌（CSRF token，用于确认提交来自领取凭据的本站浏览器）绑定匿名标识与当日日期。Cookie 或指纹任一已在当天成功提交，就拒绝再次提交，按北京时间零点恢复；无效内容或写入失败不消耗额度。浏览器指纹不能唯一代表自然人，清除标识、换浏览器或伪造请求可能绕过限制，相同配置也可能产生相同摘要；这是浏览器级防重复措施。

服务端将指纹和匿名标识转换为按日隔离的加密摘要，仅保留今天、昨天的限制记录，不对外输出。留言保留最新 2000 条，每页 20 条。持久化采用单服务进程内串行处理与原子文件替换，提交正文和当天额度写入成功后才返回成功；损坏文件不会自动覆盖。默认私有数据文件为 `.data/feedback.json`，文件同时包含签名所需随机密钥，已排除版本管理与静态访问。可用 `ZIJIAN_FEEDBACK_DATA_DIR` 指定数据目录，备份时应将此目录整体作为私有数据处理。

本地服务对每个网络地址每分钟最多接受 10 次提交尝试；上线配置另对提交按真实访问地址限速。蜜罐字段、控制字符、纯符号、大量重复字符和过多链接会被拒绝。每天一次与这些基础校验不能判断所有留言是否有意义，当前按用户选择直接公开，没有人工审核、自动内容审核或管理删除入口。

服务器部署将 `/opt/zijian/data/` 独立挂载到 `/data`，运行用户可写，更新源码不会上传、覆盖或清空数据。`ZIJIAN_TRUST_PROXY=1` 仅用于现有受信任 Nginx 入口，由入口覆盖真实访问地址；直接运行本地服务时默认不信任转发头。当前 JSON 文件存储适用于单个服务进程，扩展多实例前需改用共享数据库。

实现参考：[浏览器指纹说明](https://developer.mozilla.org/en-US/docs/Glossary/Fingerprinting)、[Cookie 属性](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。

## 使用 DeepSeek 翻译与雅思学习

1. 电脑安装 Node.js 20.12 或更新版本（当前电脑已安装）。Node.js 是运行本机翻译服务的程序。
2. 在本目录 `.env` 中配置密钥。支持 `DEEPSEEK_API_KEY` / `DEEPSEEK_API_URL`，也兼容已有的 `DATAAGENT_DEEPSEEK_LLM_API_KEY` / `DATAAGENT_DEEPSEEK_LLM_API_URL`。地址可填写 `https://api.deepseek.com`、其 `/v1` 地址或完整 `/chat/completions` 地址。
3. 双击 `启动翻译.cmd`，浏览器会打开 <http://127.0.0.1:4173>。保留启动窗口运行；关闭窗口停止服务。也可以在本目录运行 `node translation-server.mjs`。
4. “全文模式”中，电脑上双击英文单词，或拖选英文后在选中文字上双击；手机或 iPad 上长按选中英文，拖动选区手柄调整范围，再点击“翻译与学习”。手机使用底部学习面板，iPad 在空间充足时使用浮窗；软键盘或可视区域变化后，入口与面板会调整位置。支持单词、短语、句子及多句或段落；默认展示简要内容，点击“展开学习”查看搭配、句子结构、改写或仿写任务。展开和收起不会再次请求。单纯选中、调整选区、空白、纯中文、纯数字或符号不会发起分析。输入、取消选择、点击外部、按 Escape 或切换模式会收起浮窗。
5. “分句模式”默认显示范文，可点击“隐藏范文”或“全部隐藏”进行默写。显示的英文范文支持与全文模式相同的学习操作：电脑双击，手机或 iPad 长按选中再点击“翻译与学习”。单词会附带它在原文中的所在句段，跨句选择保留原文位置。隐藏范文、修改输入、重新分组、重练、导入或切换模式会收起浮窗，旧响应不会重新显示。跨组选择、答案区和中文区不触发学习分析。
6. 点击某组“显示中文”可查看整组中文翻译。中文和英文独立显示、隐藏，不改变输入或检查结果。
7. 分句输入后点击“对照检查”，将本组范文和你的输入发送给 DeepSeek。分别判断语言正确性与原意是否一致：正确改写会得到认可；真实语言错误按“你的表达、正确表达、原因”列出，修正尽量保留你的表达；另行说明与范文的表达差异及意思变化。不为孤立句段评雅思分数。“逐词核对”仍在本地比较范文用词、大小写及标点，忽略空格数量和换行差异；直接打开本地文件时也可使用。

固定使用快速模型 `deepseek-flash`，关闭思考模式。两种模式双击英文或点击“翻译与学习”时，将选中文字与必要的所在句段发送给 DeepSeek，用于判断当前词义和论证关系；上下文过长时限制在选区附近，位置无法可靠匹配时不附加上下文。点击“显示中文”时，仅发送该组范文。“对照检查”只发送本组范文和本组输入，二者须含英文且各不超过 12,000 字符。不自动分析全文。选区一次最多 2,000 字符，可选择并复制学习面板文字；输入、导入、重练和切换模式不会被旧请求结果打断。

翻译浮窗默认保留译文与简要信息，“核心用法”和“易错提醒”统一放入“展开学习”。旧缓存结果也按此布局显示，展开或收起不增加模型请求。

分句模式中，双击自己的非空输入区等同于“逐词核对”，双击自己的核对结果等同于“修改输入”，保留原文字并聚焦输入区。操作只作用于当前组，不发起模型请求；空白输入或输入法正在组合文字时不触发核对。原有按钮及范文的双击翻译学习操作继续可用，秒表不受双击切换影响。

分析遵循已确认的教学提示词：区分词、短语、句、段和片段，保持原意，不给孤立词句打雅思分数；原文错误与常见易错点分别说明，仿写任务不直接显示答案。仅给定选区及所在句段，没有作文题目时不判断是否切题。分析、评析和翻译结果仅在页面及本机服务的内存中复用，分析缓存同时匹配选区和上下文，评析缓存同时匹配范文与输入；本机服务最多保留 300 条翻译、100 条分析和 100 条评析，重启后清除。关闭浮窗或隐藏中文不取消已经开始的请求。编辑、重练、导入、重新分组或退出分句模式使进行中的评析结果失效；再次检查使用当前内容。

密钥由服务读取，不会写入网页或发送给浏览器。默认只监听本机地址；服务器部署可配置监听地址和允许的网站地址。服务只提供明确列出的页面资源，拒绝读取 `.env` 和其他本地文件。请求最长等待 30 秒，每组最多 12,000 字符；费用由 DeepSeek 按实际用量收取。余额不足、无效密钥、网络失败等会显示中文提示，可重试。

成功导入的文章与标题通过浏览器本地存储（localStorage，保留在当前浏览器和网站地址下的数据）保存，刷新或下次访问恢复最近一次成功导入的文章。只在点击“开始练习”应用有效文章时更新，预览、取消或导入失败不覆盖上一次记录。全文与分句模式使用同一篇恢复文章；输入、检查结果和秒表不保存。清除网站数据、更换浏览器或设备后需重新导入。保存失败会给出提示，本次练习仍可继续。

直接双击 `index.html` 时，原有练习不受影响；翻译需先启动服务并使用本机网页。本地文件是否允许持久保存由浏览器决定，存储不可用时不会阻止练习。

## 服务器部署与增量更新

使用固定 Node.js 基础镜像，通过目录绑定（bind mount，将服务器源码目录映射到容器）运行，更新源码无需重新构建应用镜像。Nginx 负责接收 80 和 443 端口访问，应用的 4173 端口仅供容器内部使用。

- 服务器：`47.106.182.159`；域名：`type.where.work`，需将域名的 A 记录指向服务器 IP。
- `/opt/zijian/src/`：网页、样式、脚本和服务源码，只读挂载到应用的 `/app`。
- `/opt/zijian/config/app.env`：仅保存 DeepSeek 配置，文件权限为 `600`，通过 Compose 注入；不会放入源码目录。
- `/opt/zijian/tls/`：传输层安全证书（TLS，用于加密网站访问），只读挂载给 Nginx，目录权限 `700`、私钥权限 `600`；本机对应 `tls/type.where.work.pem` 和 `tls/type.where.work.key`，该目录已排除版本管理。
- `/opt/zijian/compose.yaml`、`/opt/zijian/nginx.conf`：容器和网站入口配置，对应本项目 `deploy/` 下的文件。

在本机 PowerShell 执行首次部署或更新：

```powershell
.\deploy\Deploy.ps1
```

脚本比较文件内容摘要（SHA-256，用于判断文件是否变化的校验值），仅上传新增或变化的文件。前端文件更新后刷新网页即可；服务源码或部署配置变化时，脚本重建容器以加载新内容。初次部署时只从本机 `.env` 提取 DeepSeek 所需配置，不上传其他配置；后续部署默认保留服务器密钥。明确需要更新密钥时执行：

```powershell
.\deploy\Deploy.ps1 -UpdateSecrets
```

加密访问地址为 `https://type.where.work`。访问 `http://type.where.work` 时自动返回 308 永久重定向到 HTTPS，保留路径、查询参数、请求方法和请求体；`http://47.106.182.159` 与服务器本机 HTTP 自检继续直接访问。证书覆盖域名，不覆盖公网 IP，因此使用 IP 进行 HTTPS 访问不能通过证书域名校验。部署脚本校验证书有效期、域名、证书链及私钥匹配，并在启动前验证 Nginx 配置；证书变更后执行同一个部署命令即可更新，无需传输其他未变更文件。续期需要替换本机证书及私钥后再次部署；当前没有配置自动续期。云端安全组需要允许入方向的 TCP 80 和 443 端口。

服务通过 `ZIJIAN_HOST=0.0.0.0` 在容器内接受连接，通过 `ZIJIAN_PUBLIC_ORIGINS` 指定完整访问地址，以英文逗号分隔；本机启动默认继续监听 `127.0.0.1`。域名、协议或访问端口变更时，要同步修改 Compose 的允许地址和 Nginx 入口配置。访问域名（Host）必须在允许名单内，有请求来源（Origin）的请求还必须与当前访问地址一致。

入口对翻译与分析请求按客户端 IP 限速，每分钟 10 次，允许短时突发 5 次；现有服务仍限制最多 3 个并发上游请求。这是公开网站，知道网址的用户可使用所配置账户的翻译额度；如需仅供指定人员使用，应另加登录控制。
