## 动手练一句

1. 选一篇自己想练的英文文章，先读懂其中一句。
2. 隐藏原文，试着把这句话写出来。
3. 对照核对漏词、拼写和标点，再回到原句理解表达。

[打开网站试试](https://type.where.work/)。网站提供整篇与分句练习、逐词核对、好词好句标记等功能；当前体验与使用说明以网站为准。

## 使用模板

下载 [note-template.html](templates/note-template.html)，直接用浏览器打开，按文件中的注释替换图片、文字和链接。模板不需要安装依赖，也不连接账号或支付服务。
